# Aspine

So to start/dev:

- `bun i`

- `bun watch` (watch for code changes, on save it formats and compiles tailwind)

- `bun dev` (for dev env)

- `bun run build && bun preview` (for prod env)

- `bun start:dev` (does all of the above, for dev)

- `bun start:prod` (does all of the above, for prod)
